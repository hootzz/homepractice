## 적용 범위와 공통 계약

[정책](./HOME_PRACTICE_REDESIGN.md), [데이터 계약](./HOME_PRACTICE_DATA_SPEC.md), [출처 감사](./SESSION_SOURCE_AUDIT.md), [구현 감사](./IMPLEMENTED_PRACTICE_AUDIT.md), [한국어/audio 대응](./KOREAN_MBCT_AUDIO_MAPPING.md), [PDF 검증](./PDF_EXPORT_VERIFICATION.md)을 기준으로 작성했다. 현재 사용자 문구는 `src/content/workbook.ts`가 기준이며 `src/content/sessions.ts`는 역사적 NPC·장면 참고다. 최신 발표자료·원본 캡처·V3.3 원문을 새로 확인한 것은 아니다.

- 아래 S1–8은 기존 `week_1`–`week_8` WeeklyTask의 표현 교체안이다. 현재 이 과제들과 S3 Regular 두 개는 **demo 검토 후보**이며 actual 출판 승인을 뜻하지 않는다. 원래 manifest에 없는 항목을 이 문서로 열지 않는다.
- 접근은 Session Complete → 해당 Bundle, 이전 Regular 누적 유지, S8 완료 뒤 Repertoire에서 직접 Kit 선택. 새로운 참여자별 action/receipt gate는 없다.
- 화면은 A 장면 cue → B 선택 가능한 작은 조작 → C 한 번에 한 단계 → D 선택 기록. 선택하지 않아도 `선택 없이 이어가기`로 진행할 수 있다. 손동작 기회는 제공하지만 응답을 수행 조건으로 만들지 않는다.
- B의 선택과 C의 펼침 상태는 화면 내 임시 UI 상태다. 자동 record·Kit·완료·분석 데이터로 저장하지 않는다. 기록은 D에서 사용자가 입력하고 `기록 저장`을 누른 경우에만 기존 스키마로 저장한다. 질문·연습명 snapshot을 남기고 과거 기록을 새 질문으로 덮어쓰지 않는다.
- C 공통 버튼: `다음 장면`이 아니라 `이어서 살펴보기`; 뒤로는 `이전 안내`; 언제든 `여기서 마치기`. 마지막은 `경험 남기기`와 `기록 없이 돌아가기`. “다음”은 안내 이동이지 실제 수행 확인이 아니다.
- reflection은 회기별 최대 두 질문만 이 흐름에 노출한다. 아래 기존 key를 사용한다. 다른 기존 답변·기록은 삭제하지 않는다. 모두 optional, `잘 모르겠어요` 허용, 공백만 있으면 저장하지 않는다.
- 시간·빈도·audio requirement는 기존 근거 상태를 유지한다. 화면을 나누는 것은 연습을 1–5분으로 단축한다는 뜻이 아니다. 검증된 한국어 공식 audio가 없어 아래 모든 흐름은 text로 작동한다.
- NPC 한 줄은 **이번에 쓴 제안 카피**이며 원본 대사 인용이 아니다. 구 `sessions.ts`의 NPC 배역은 최신 배포 미확인이다. 확인 전에는 NPC 이름·초상·말풍선 없이 익명 안내문으로 렌더링한다. 장소명이 확인되지 않은 회기는 새 고유 지명을 만들지 않는다.

## S1 · 익숙한 순간, 새롭게 보기

**대상:** `week_1` / 익숙한 행동 앞에서 멈추기 / `sensory`.
**Preserved function / 목적:** 자동 행동을 잠시 끊고 익숙한 대상을 감각적 호기심으로 다시 보기. 특정 감각이나 평온을 만들어내는 과제가 아니다.
**A 장면 cue:** 먹기 전 손 위의 호두 겉면과 열린 알맹이 근접 컷. 현재 구현의 호두를 사용하고 과거 도토리와 섞지 않는다. 장소는 관찰하던 자리, 정확한 배경은 캡처 대기. 구 배역 다람쥐 검토용 한 줄: `익숙한 것도 잠깐 멈추면 다르게 보일 수 있어요.` Intro: `호두를 살펴보던 순간에서, 오늘의 익숙한 행동으로.`
**B 작은 인터랙션:** `어떤 순간에서 시작할까요?` 단일 선택칩 `물 마시기` / `손 씻기` / `내가 떠올린 순간` / `잘 모르겠어요`. 선택은 아래 맥락 표시만 바꾸며 안내의 감각 범위를 제한하지 않는다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 익숙한 순간 | 고른 행동을 시작하기 전, 잠깐 멈춰봐요. |
| 2 | 하나의 감각 | 보이는 것, 닿는 느낌, 몸의 움직임 중 눈길이 가는 것을 살펴봐요. |
| 3 | 그대로 이어가기 | 느껴지는 만큼 알아차리며 하던 행동을 이어가요. 특별한 느낌이 없어도 괜찮아요. |

**D optional reflection:** `무엇을 알아차렸나요?` → `noticed`; `어떤 순간이었나요?` → `moment`.
**줄임 / 보존:** 긴 호두 설명은 두 개의 근접 이미지로 대체. 자동 행동의 중단과 직접 감각이라는 핵심은 본문에 남긴다. 먹기 연습을 새 Regular로 만들지 않는다.
**UI / visual:** 호두 이미지 `겉 / 안` 탭은 장면 보기만 전환한다. 회전·식사 시뮬레이션 없음. 따뜻한 갈색 오브젝트와 얇은 선; 실물 캡처 없으면 “장면을 떠올리는 그림”으로 표기한 호두 선화.
**Audio / Kit:** audio 연결 없음. WeeklyTask는 Kit 대상 아님. 하단 `계속 가져갈 연습`은 이미 열린 Regular가 있을 때만 표시하며 빈 슬롯·수집 수는 보이지 않는다.

## S2 · 생각에서 몸으로 돌아오기

**대상:** `week_2` / 기다리는 동안 몸 살피기 / `body`.
**Preserved function / 목적:** 생각 중심 설명에서 몸의 직접 경험으로 이동하고 생각·감정·몸을 구분한다. 생각 수정이나 정식 Body Scan 대체가 아니다.
**A 장면 cue:** 기다리던 자리와 멈춘 발/손의 화면 일부. 구 배역 거북이는 현재 카피에 있으나 배포 초상·정확한 장소는 확인 전 사용하지 않는다. 제안 한 줄: `기다리는 동안 몸에서는 무엇이 느껴졌나요?` Intro: `기다리던 장면에서, 지금 몸의 느낌으로.`
**B 작은 인터랙션:** 접힌 `몸` 카드를 탭하면 `느껴지는 곳이 있나요?`가 나타남. 작은 텍스트칩 `손` / `어깨` / `배` / `다른 곳` / `잘 모르겠어요`. 신체 지도로 모든 부위를 탐색하도록 요구하지 않는다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 기다리던 순간 | 일상에서 무언가를 기다리던 순간을 떠올려요. |
| 2 | 몸의 느낌 | 몸 어디에서 어떤 감각이 느껴졌나요? 지금 느껴지는 몸도 살펴봐요. |
| 3 | 함께 있던 생각 | 그때 어떤 생각이 함께 있었는지 알아봐요. 바꾸지 않아도 괜찮아요. |
| 4 | 함께 있던 감정 | 감정이나 기분은 어땠나요? 생각, 감정, 몸이 분명히 나뉘지 않아도 괜찮아요. |

**D optional reflection:** `몸에서는 무엇이 느껴졌나요?` → `body`; `어떤 생각이 함께 있었나요?` → `thought`.
**줄임 / 보존:** “한 경험 안에 세 요소가 있다”는 설명을 순차 카드로 분리. 몸→생각→감정 구분은 생략하지 않는다. 마지막 기록이 두 질문이어도 감정을 살피는 연습 단계는 유지한다.
**UI / visual:** 한 카드씩 펼치고 이전 카드의 제목만 접어서 남긴다. 장소는 기다리던 자리, 오브젝트는 손/발 접촉면. 몸 색상·온도 수치나 감정 진단 없음.
**Audio / Kit:** Body Scan audio/Regular는 pending 그대로. 이 짧은 과제를 바디 스캔으로 표시하지 않는다. WeeklyTask는 Kit 대상 아님; 기존 Repertoire만 하단에서 이어보기.

## S3 · 마음이 다른 곳에 갔을 때

**대상:** `week_3` / 마음이 간 곳 알아보기 / `attention`; 이미 접근 가능한 `walking_return`과 연결.
**Preserved function / 목적:** 주의가 떠난 것을 알아차리고 실패로 평가하지 않으며 발의 감각으로 돌아온다. 집중 지속 시간이나 돌아온 횟수를 재지 않는다.
**A 장면 cue:** 숲길의 발밑과 발이 닿는 지점. 화면 전체 풍경 hero 대신 게임의 발밑 작은 캡처. 구 배역 사슴 제안 한 줄: `마음이 다른 곳에 가도, 알아차린 뒤 돌아와요.` Intro: `숲길에서 발의 감각으로 돌아오던 것처럼.`
**B 작은 인터랙션:** `어떤 길에서 이어가 볼까요?` 칩 `집 안의 익숙한 길` / `학교에서 걷는 길` / `내가 떠올린 안전한 길` / `지금은 살펴보기만`. 실제 걷는 동안 화면 탭을 요구하지 않는다. 걷기 전에 안내를 보고 휴대폰을 내려둘 수 있다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 발이 닿는 곳 | 익숙하고 안전한 길에서, 발이 바닥에 닿는 느낌을 살펴봐요. |
| 2 | 마음이 간 곳 | 마음이 다른 곳에 갔음을 알아차리면, 어디로 갔는지 잠깐 알아봐요. |
| 3 | 다시 감각으로 | 잘못했다고 평가하지 않고 발과 다리의 감각으로 돌아와요. |

**D optional reflection:** `마음은 어디로 갔나요?` → `attention_went`; `무엇을 느끼며 돌아왔나요?` → `return_anchor`.
**줄임 / 보존:** 숲의 소리·빛 설명을 발밑 cue로 압축하고 감각 복귀·비평가성은 유지. 마음이 떠나는 것을 일부러 만들어내지 않는다.
**UI / visual:** 시작 전에 `안내 한눈에 보기`로 세 장을 순서대로 열람 가능. 실천 중 화면 조작 없음. 돌아온 횟수 탭/발걸음 추적/선 따라가기 없음. 녹색은 안내 요소에만 사용.
**Audio / Kit:** 한국어 audio 없음. 이미 열린 `walking_return`만 `걸으며 돌아오기` 링크로 연결. WeeklyTask 자체는 Kit 대상 아님. Regular 후보는 사전 승인 뒤 회기 완료로 열리고 S8에서 선택 가능.

### S3의 기존 Regular 표현을 적용하는 방법

`walking_return`: 위 발밑 cue와 안전한 맥락 선택을 공유하되, 본문은 `걸음 느끼기`(안전한 길에서 걸음을 느껴봐요.) → `발과 다리`(발바닥, 발, 다리의 움직임에 주의를 기울여요.) → `돌아오기`(마음이 다른 곳에 가면 평가하지 않고 감각으로 돌아와요.)로 표시한다. 기록은 `attention_went` / `return_anchor`.

`breathing_space`: 호흡을 따라 커졌다 작아지는 애니메이션 대신 동일 크기의 접힌 카드 세 장. 시작 조작은 `세 단계 펼쳐보기`. `지금의 경험`(몸의 감각, 감정, 생각과 하고 싶은 마음을 알아봐요.) → `호흡에 모으기`(호흡을 바꾸지 않고 자연스러운 들숨과 날숨의 감각에 주의를 모아요.) → `몸과 주변으로`(몸 전체와 주변으로 주의를 넓혀 다음 순간으로 이어가요.). 상시 짧은 문구 `진정되거나 감정이 바뀌어야 하는 연습은 아니에요.` 기록은 `return_anchor` / `noticed_after`(`돌아온 뒤 무엇을 알아차렸나요?`). 세 단계를 단일 호흡칩·타이머로 대체하지 않는다. 현재 두 Regular는 demo 후보이며 이 추가 설명이 actual 승인이나 신규 도입은 아니다.

## S4 · 반응하기 전, 잠깐 멈추기

**대상:** `week_4` / 반응의 흐름 돌아보기 / `reactivity_v3`.
**Preserved function / 목적:** 불편함→하고 싶은 마음→행동→그 뒤의 경험을 알아보는 Recognize. 반응 억제, 더 나은 선택 연습, allowing·호흡 단계로 확장하지 않는다.
**A 장면 cue:** 짧은 경험 흔적 네 칸 `불편함 / 하고 싶은 마음 / 행동 / 그 뒤`. 이것은 **웹 설명 그림**이며 실제 게임 UI 캡처인 척하지 않는다. 실제 코드 열매·회피 장면과 이전 안개/곰·고슴도치 버전의 대응이 미확인되어 특정 장소·NPC를 배포하지 않는다. 구 배역 곰 제안 한 줄: `바꾸기 전에, 이어진 흐름을 살펴봐요.` Intro: `불편한 순간 뒤에 무엇이 이어졌는지 돌아봐요.`
**B 작은 인터랙션:** 네 칸 중 기억이 먼저 나는 칸을 탭해 설명을 펼친다. “기억이 시작된 곳” 표시일 뿐 순서를 채우는 시험이 아니다. 이후 단계는 아래 순서로 안내한다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 불편했던 순간 | 가벼운 불편함이 있었던 장면을 떠올려요. 몸에서는 무엇이 느껴졌나요? |
| 2 | 하고 싶어진 것 | 그 뒤에 무엇을 하고 싶어졌는지 살펴봐요. |
| 3 | 이어진 행동 | 실제로 어떤 행동이 이어졌나요? 좋고 나쁨을 정하지 않아도 괜찮아요. |
| 4 | 그 뒤의 경험 | 그 뒤에는 무엇이 있었나요? 분명하지 않은 부분은 그대로 두어요. |

**D optional reflection:** `무엇을 하고 싶어졌나요?` → `impulse`; `그 뒤에는 무엇이 있었나요?` → `after`.
**줄임 / 보존:** 반응에 대한 설명 문단을 네 칸의 흐름으로 대체. 충동과 행동은 서로 다른 것으로 남긴다. “다음에 무엇을 선택할까”·호흡·anchor 안내는 이 흐름에 추가하지 않는다.
**UI / visual:** 한 칸씩 아코디언, 화살표는 읽는 순서만 표현. 정답 순서 맞추기·drag 필수화 없음. 추상 선 그림에 `반응의 흐름` alt. 장소·NPC 확정 후 같은 크기의 실제 장면 crop으로 교체 가능.
**Audio / Kit:** audio 연결 없음. stale responsive breathing controller를 근거로 새 Regular를 열거나 기존 호흡을 중복 노출하지 않는다. WeeklyTask는 Kit 대상 아님; 이전 Regular만 누적 유지.

## S5 · 불편한 마음에 자리 내주기

**대상:** `week_5` / 가벼운 불편함 살펴보기 / `allowing_v3`.
**Preserved function / 목적:** 불편함을 즉시 없애려는 마음을 알아보고 가능한 범위에서 몸의 감각과 접촉한다. allowing은 참기·위험 감수·불편함 좋아하기가 아니다.
**A 장면 cue:** 비/물웅덩이 주변에서 손의 감각을 살피는 작은 컷. 실제 개정 흐름의 수문·비·손 anchor 중 캡처를 선택하되 오래된 반응선택 버전과 혼합하지 않는다. 구 배역 개구리 제안 한 줄: `가능한 만큼 살펴보고, 필요하면 돌아와요.` Intro: `비를 멈추기보다, 몸에서 느껴지는 것을 살펴봤어요.`
**B 작은 인터랙션:** `돌아올 감각을 먼저 골라둘까요?` 선택칩 `손의 느낌` / `발이 닿는 느낌` / `지금은 고르지 않기`. 이 선택은 안전 경로를 쉽게 찾는 UI이지 anchor의 성공 확인이 아니다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 가벼운 경험 | 안전한 일상에서 지금 다룰 수 있는 가벼운 불편함을 떠올려요. |
| 2 | 없애고 싶은 마음 | 곧바로 없애거나 바꾸고 싶은 마음과 몸의 느낌을 알아봐요. |
| 3 | 가능한 만큼 | 바꾸려 애쓰지 않고, 가능한 만큼 몸의 감각과 함께 있어 봐요. |
| 4 | 돌아오거나 멈추기 | 필요하면 손이나 발의 익숙한 감각으로 돌아와요. 여기서 멈춰도 괜찮아요. |

**D optional reflection:** `몸의 감각과 함께 무엇을 알아차렸나요?` → `noticed`; `돌아올 감각은 무엇이었나요?` → `anchor`.
**줄임 / 보존:** 긴 허용 설명을 감각 선택과 순차 카드로 대체. `위험하거나 해로운 상황에 머무르는 연습은 아니에요.`는 접지 않고 유지한다.
**UI / visual:** `익숙한 감각으로 돌아오기`와 `여기서 마치기`를 모든 단계에서 사용 가능하게 한다. 전자는 4번 안내를 열며 stage 완료를 만들지 않는다. 빗소리 자동재생·물 높이 채우기·버티는 타이머·hold 조작 없음.
**Audio / Kit:** audio 연결 없음. 비 asset은 청각 가이드로 간주하지 않는다. 독립 allowing Regular 신설 없음. WeeklyTask는 Kit 대상 아님.

## S6 · 생각과 사실 사이

**대상:** `week_6` / 한 장면 나누어 보기 / `thought_v3`.
**Preserved function / 목적:** 사건·상태·해석을 구분하고 생각과 거리를 둔 뒤 도움이 될 대응을 살핀다. 생각을 논박·삭제하거나 긍정적 설명으로 교체하는 과제가 아니다.
**A 장면 cue:** 구현 감사에 있는 사건/상태/해석 세 칸과 생각구름. 동일 사건 이미지의 crop은 배포 캡처 확인 뒤 사용. 별도 사실/추론 기억카드 버전과 섞지 않는다. 구 배역 독수리 제안 한 줄: `같은 일에도, 상태와 설명이 함께 있었어요.` Intro: `한 장면을 사건, 상태, 해석으로 나누어 봐요.`
**B 작은 인터랙션:** 세 탭 `있었던 일` / `당시 상태` / `떠오른 설명`을 누르면 각각 `직접 확인한 일` / `몸과 마음의 상태` / `마음이 붙인 의미`가 보인다. 분류 퀴즈가 아니라 용어를 자기 속도로 펼치는 동작이다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 한 장면의 세 부분 | 실제 일, 당시 몸과 마음, 떠오른 설명을 하나씩 살펴봐요. 세 탭을 자유롭게 오가도 괜찮아요. |
| 2 | 생각을 바라보기 | 그 설명이 떠올랐다는 것을 한 걸음 떨어져 바라봐요. 맞고 틀림을 결론내리지 않아도 괜찮아요. |
| 3 | 익숙한 안내 펼치기 | 필요하면 앞에서 이어온 3단계 안내를 다시 펼쳐봐요. |
| 4 | 지금 도움이 될 것 | 지금 무엇이 도움이 될까요? 아직 떠오르지 않아도 괜찮아요. |

**3번 조건:** `breathing_space`가 현재 release와 완료 상태에서 접근 가능할 때만 `3단계로 돌아오기` 펼침/링크 제공. 펼치면 S3의 현재경험→자연스러운 호흡→몸/주변 세 카드를 온전히 보여준다. 미접근이면 이 선택 단계 전체를 생략해 세 단계 흐름으로 렌더링한다. 새 연습 unlock·호흡으로 진정하기 처방은 없다.
**D optional reflection:** `한 걸음 떨어져 보니 무엇을 알아차렸나요?` → `distance`; `지금 무엇이 도움이 될까요?` → `helpful`.
**줄임 / 보존:** 장문의 사실/생각 설명을 세 탭과 한 줄 정의로 대체. 1번 탭 내용은 동시에 세 문단을 표시하지 않는다. 탈중심화와 도움될 선택은 본문에 남긴다.
**UI / visual:** 카드가 날아가며 생각을 없애는 표현 금지. 구름은 생각이 있다는 맥락 표시만 하며 탭해서 지우지 않는다. 최신 S6 Respond 흐름과 Unity 대응은 content TODO 그대로.
**Audio / Kit:** 한국어 audio 없음. 이미 접근 가능한 호흡 Regular만 재사용하며 WeeklyTask 자체는 Kit 대상 아님. 새로운 S6 Regular를 만들지 않는다.

## S7 · 나를 돌보는 작은 선택

**대상:** `week_7` / 오늘의 활동 돌아보기 / `care`.
**Preserved function / 목적:** 활동이 자신에게 미친 영향을 살피고 의도적인 자기돌봄 행동을 고른다. 활동을 고정적으로 좋음/나쁨으로 평가하거나 생산성을 최적화하지 않는다.
**A 장면 cue:** 실제 활동을 살펴보던 카드 화면 crop. 장소·소품은 배포 캡처 전 추정하지 않는다. 구 배역 강아지 제안 한 줄: `같은 활동도 날마다 다르게 느껴질 수 있어요.` Intro: `오늘의 활동이 나에게 남긴 느낌을 살펴봐요.`
**B 작은 인터랙션:** 활동을 마음속으로 떠올린 뒤 `채워 줬어요` / `지치게 했어요` / `상황에 따라 달랐어요` / `내 말로 살펴볼게요` / `잘 모르겠어요` 칩. 선택은 임시이고 활동의 영구 라벨로 저장하지 않는다. 직접 입력은 필수 아님.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 오늘의 활동 | 오늘 한 활동들을 떠올리고, 살펴보고 싶은 것부터 봐요. |
| 2 | 나에게 남긴 느낌 | 그 활동은 나에게 어떤 영향을 주었나요? 여러 느낌이 함께 있어도 괜찮아요. |
| 3 | 작은 돌봄 선택 | 다음 며칠에 이어가고 싶은 작은 돌봄 행동이 있나요? 지금 떠오르는 만큼 살펴봐요. |

**D optional reflection:** `나에게 어떤 영향을 주었나요?` → `effect`; `이어가고 싶은 작은 행동이 있나요?` → `small_action`.
**줄임 / 보존:** 소모/회복의 긴 설명을 다섯 칩으로 대체. 상황 의존성과 “모르겠음”을 같은 수준으로 남긴다. 활동 몇 개를 반드시 적게 하지 않는다.
**UI / visual:** 선택칩은 동일 색조/강조; 채워줌=녹색, 지침=빨강 분류 금지. 정답 추천·기록기반 행동 추천 없음. 하단 `계속 가져갈 연습`에서 이미 열린 Regular를 둘러볼 수 있지만 Kit 선택 UI는 열지 않는다.
**Audio / Kit:** audio 연결 없음. 돌봄 행동은 새로운 Regular/Kit 항목이 아니다. 기존 연습을 다시 만나는 약한 연결만 제공하고 S8 개인 선택을 예고하는 카운트다운은 두지 않는다.

## S8 · 내 일상에 가져갈 연습

**대상:** `week_8` / 나에게 맞게 이어가기 / `integration`; 별도 기존 Practice Kit 화면으로 연결.
**Preserved function / 목적:** 누적된 Regular를 실제 삶의 cue·상황·개인 이유와 연결해 자기주도적으로 이어간다. 새 library, 선택 개수 목표, 수행 약속은 없다.
**A 장면 cue:** 현재 Repertoire에 있는 연습의 작은 기억 이미지들을 목록으로 다시 보여준다. 실제 S8 꽃 회고 코드가 있어도 웹에서는 빈 꽃 슬롯·수집판으로 바꾸지 않는다. 구 배역 꿀벌 제안 한 줄: `내가 이어가고 싶은 연습을 직접 골라요.` Intro: `지금까지 이어온 연습을 내 일상에 놓아봐요.`
**B 작은 인터랙션:** 접근 가능한 Regular 카드에서 `안내 다시 보기`로 내용을 펼친다. 어느 카드도 자동선택하지 않는다. Repertoire가 비어 있으면 `아직 열린 연습이 없어요.`와 `이야기로 돌아가기`; 후보를 채우지 않는다.

| Step | 제목 | 짧은 사용자 문구 / 선택 |
|---|---|---|
| 1 | 다시 만나기 | 지금까지 열린 연습을 살펴봐요. 익숙한 안내를 다시 펼쳐봐도 좋아요. |
| 2 | 직접 고르기 | 일상에 가져가고 싶은 연습을 골라요. 지금 고르지 않아도 괜찮아요. |
| 3 | 일상과 연결하기 | 언제, 어떤 상황에서 이어가고 싶나요? 나에게 어떤 이유가 있는지도 원하면 적어봐요. |

**Kit 연결:** 2번 `일상에 가져갈 연습 고르기`는 기존 S8-gated `/my-practice`로 이동한다. 후보는 현재 Repertoire Regular만. `cue / situation / personalReason` 모두 optional, 개수 강제 없음, 제거해도 Repertoire 유지. WeeklyTask 화면의 단계 이동만으로 Kit을 만들지 않는다. 작성 중 화면 이동은 입력을 보존하고 저장 실패 때 지우지 않는다.
**D optional reflection:** `언제 어떤 연습을 이어가고 싶나요?` → `cue`; `나에게 어떤 이유가 있나요?` → `reason`. 이 Entry는 Kit 필드와 별개다. 기록 응답을 Kit으로 자동 복사하거나 Kit 저장을 record로 변환하지 않는다.
**줄임 / 보존:** “연습을 1–3개 선택” 같은 legacy 제한은 사용하지 않고 실제 누적 카드로 긴 회고를 대체. 선택의 자율성과 개인 생활 맥락은 유지한다.
**UI / visual:** 체크 아이콘은 현재 선택 여부만 의미한다. badge·수집 개수·완료율 없음. 선택 카드는 180ms fade로 변화를 알려 주되 화면에서 사라져 초점을 잃지 않도록 한다. 기록/PDF는 실제 저장한 Entry와 최종 Kit만 사용한다.
**Audio / Kit:** 자체 audio 없음. 선택한 기존 Regular의 검증된 audio 정책만 따른다. `BLOCKED_GAME_KIT_SYNC` 유지: 웹 Kit이 게임 Kit과 동기화된 것처럼 표현하지 않는다.

## 구현 시 매핑과 self-check

표현 데이터는 기존 `WeeklyTask.id`/`Practice.id`를 key로 둔 별도 presentation mapping으로 구현한다. 권장 최소 필드는 `sceneCue {imageRef?, alt, intro, sourceStatus}`, `entryInteraction {kind, prompt, options}`, `steps [{id,title,body}]`, `reflectionKeys`. NPC 한 줄은 검수용 `proposedNpcLine`이며 확인 전 runtime의 발화자 속성으로 넣지 않는다. `imageRef` 미확인은 null; 존재하지 않는 asset 경로를 만들지 않는다. 공통 패턴 상세는 [INTERACTION_PATTERN](./HOME_PRACTICE_INTERACTION_PATTERN.md), 현재/수정 문구는 [UI_COPY_TABLE](./HOME_PRACTICE_UI_COPY_TABLE.md)을 따른다.

| 검사 | 판정 / 근거 |
|---|---|
| 기존 policy 유지 | YES · manifest·Bundle·회기 완료·누적·S8 gate 변경 없음 |
| 텍스트 감소 | YES, 기본 동시 노출 기준 · 한 단계 1–2문장과 제목만 노출. 전체 기능 설명 총량을 삭제한 것은 아니며 실제 렌더링 줄 수는 구현 QA 대상 |
| 구체적인 scene cue | YES, 설계 명세 기준 · 호두/기다림의 손·발/숲길 발밑/반응 흔적/비와 손/세 칸/활동 카드/기존 연습 목록. 미확인 배경·배역은 명시적으로 보류 |
| 회기별 작은 조작 | YES · 상황칩/몸 카드/길 선택/흐름 펼침/anchor 선택/세 탭/영향칩/연습 펼침. 응답 없이 진행 가능 |

| 보상 금지 | YES · 점수·streak·성공판정·타이머·수집·완료율 없음 |
| 세계관 연결 | YES, 제안 기준 · 출처별 장면 오브젝트를 사용하되 NPC/캡처 검증은 남음 |

| mobile workbook | YES, 설계 기준 · 카드/칩/펼침과 한 행동씩 안내. 390px 실화면 검증은 구현 뒤 필요 |

**남은 visual/content 의존성:** authoritative V3.3/배포 장면·NPC 매칭, 사용 가능한 실제 screenshot 권리/asset, S4–6 버전 대조, S2 Body Scan 교육 확인, S3 도달성, Regular 출판 승인, 한국어 공식 audio/권리. 이 rewrite가 어느 것도 확인 완료로 바꾸지 않는다.
