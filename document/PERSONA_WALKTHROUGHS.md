# Persona walkthroughs — Home Practice

2026-10-06. 정책·틀(REDESIGN §4a–§4c, DATA_SPEC)은 그대로 두고, 서로 다른 사용자가 실제로 눌러 봤을 때 어색한 곳을 찾아 고친 기록이다. 페르소나의 바람을 전부 들어주지는 않는다. MBCT 정합성, 선택적 기록, 보상·압박 금지, Session Complete → Bundle 규칙과 충돌하는 요청은 반영하지 않는다.

## 방법

`personas.cjs`(스크래치, playwright-core + 로컬 Chrome)가 페르소나마다 50회 무작위 경로를 production 빌드에서 실제로 누른다: 홈/회기/정식 연습 진입 → 오늘 해보기 → 단계 이동(칩·직접 적기·이전·펼치기·새로고침) → 마지막 단계에서 경험 남기기(본문/빈칸/잘 모르겠어요/취소) 또는 여기서 마치기. 매 단계 검사: 가로 넘침 없음, `화면은 닫아도` 없음, 출처 라벨 없음, 첫 화면 CTA 하나·폼 없음, reveal/단계 이동 뒤 focus, 마지막 단계 전 끝 선택지 없음, 기록은 글이 있을 때만 생성, 마치기는 홈으로, 완료 상태 불변, 44px 터치 영역, 앱 오류 없음. 각 페르소나의 처음 두 실행은 단계별 스크린샷을 남겨 사람이 보듯 다시 봤다.

## 발견하고 고친 것

| 누가 | 무엇이 어색했나 | 고친 것 |
|---|---|---|
| 모두 | 기록 토글이 화면 끝에 계속 붙어 다님 | 마지막 단계에서만 `경험 남기기 / 여기서 마치기` 두 선택지. 남기기를 누르면 그 자리에서 폼, `남기지 않기`로 돌아옴 |
| 모두 | 정식 연습이 "다시 해볼 수 있는"·"사슴에서 열린"으로 회기에 묶여 보임 | 하단 `언제든 할 수 있는 마음챙김 연습` 카드(이름·한 줄·한국어 안내 n분), 출처 회기 라벨 제거, 정식 연습 화면 eyebrow `마음챙김 연습` |
| 순자 | 기록을 연 뒤 `이전`이 폼 아래에 남음 | 마지막 단계에서 `이전`을 선택지 위로 |
| 지원·예린 | S8 마지막 단계에서 `Practice Kit 열기` · `이전` · `여기서 마치기`가 흩어짐 | Kit 열기를 끝 선택지로 옮겨 `[Practice Kit 열기] [여기서 마치기]` |
| 예린 | S6 "생각이 강하게 붙었던 순간"이 무거운 일을 고르게 할 수 있음 | S6에 `감당하기 힘든 일이라면 더 가벼운 순간을 골라도 괜찮아요.` (S5의 안전 문구와 같은 자리) |

| 하은 | `남기지 않기`를 누르면 focus가 사라짐 | focus를 `경험 남기기` 버튼으로 되돌림 |

| 지원 | S8 `Practice Kit 열기`가 두 줄로 꺾임 | 끝 선택지 버튼 줄바꿈 금지 |
| 예린 | 빈 기록을 저장하면 `기록 보기`가 주 버튼으로 나옴(볼 기록이 없음) | 빈 저장 뒤에는 `여기서 마치기`만 |

## 반영하지 않은 바람

- 민호: "단계 없이 한 줄만" — 사용자 결정(§4c)으로 3–5단계 유지. 대신 각 단계 1–2문장.
- 도윤: "효과가 있다는 근거를 앞에" — 효과·이득 마케팅 금지 원칙.
- 지원: "연속 며칠째인지 보고 싶다" — streak 금지.
- 예린: "기록에 감정 점수" — 점수·분석 금지.
